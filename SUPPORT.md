# Usage Flipper — Support

For support or feature requests, please use [GitHub Issues](https://github.com/smo82-dev/UsageFlipper/issues).

## Troubleshooting

**No percentage appears:** Confirm you are signed into the relevant AI provider in the same browser. Some integrations may not yet be available.

**Figures look outdated:** Give the extension a moment to update its usage reading. Usage information depends on the provider's response and may not exactly match a page updated at a different time.

**A floating widget covers part of a webpage:** Drag it to another position or disable floating widgets through the extension toolbar.

**The extension interferes with a website:** Disable it on the affected page, then report the website address, browser version and extension version in an issue.

## Report safely

Please include a description of the issue, your browser and extension versions, and screenshots where helpful. **Never share session cookies, access tokens, passwords, full request headers or payment details.**

For privacy information, read [PRIVACY.md](PRIVACY.md).
