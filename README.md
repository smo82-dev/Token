# Usage Flipper

**Your AI limits. One little circle.**

Usage Flipper is a browser extension designed to display usage allowances and reset countdowns in small movable widgets while you browse. Tap or click a widget to flip between the available allowance windows.

This repository is for **public documentation only**. It does **not** contain the extension source code.

## Availability

Usage Flipper currently supports live ChatGPT Work/Codex usage retrieval in tested Chrome sessions. Additional provider options may appear in the interface before their integrations are available or fully verified.

Usage Flipper is independently developed and is not affiliated with or endorsed by the AI service providers it supports.
